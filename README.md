One line, under 200 characters, that gets you out of work and gets a laugh — an entry for make.fun's "The Funniest Sick-Day Excuse" bounty.

## The entry

> Sorry, can't come in today — my Fitbit says I slept nine hours and still woke up exhausted, so I've filed a warranty claim on myself and I'm waiting for the replacement.

## Run it

```sh
node main.ts
```

Writes the single line to `/output/entry.txt`. No dependencies, no network, no API keys — the line is written by the program itself, deterministically.
